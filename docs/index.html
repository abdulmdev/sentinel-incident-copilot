✈️ Why Sentinel exists: the cockpit idea

Airliners don't rely on a pilot's nerve at 3 a.m. On-call engineers shouldn't have to either.

When something fails in a modern airliner, Airbus's ECAM and Boeing's EICAS show the alert, the affected systems and the checklist to run, and Airbus's flight-envelope protection stops inputs outside safe limits. The pilot stays in command; the automation keeps the right next step in front of them, so stress, fear or fatigue don't turn a manageable failure into a reactive one.

Production incidents have the same shape: paged at night, dashboards screaming, the fast reactive move is tempting (roll back whatever deployed last, restart everything). Sentinel brings the cockpit discipline to on-call:

The goal isn't to replace the engineer. It's to make the calm, correct call the easy one, at any hour. Sentinel is not affiliated with Airbus or Boeing; the comparison describes a design philosophy.

What happens when production breaks

  1. Detect. Prometheus fires; the incident opens itself, deduplicated and correlated per service.
  2. Investigate. A LangGraph agent calls MCP tools (deploys, logs, metrics, runbooks) within hard budgets.
  3. Diagnose. Ranked root causes, each cited to evidence; deterministic guardrails block unsafe actions.
  4. Approve. Nothing touches production until a human says yes.
  5. Execute once. Approval mints a 5-minute, single-use capability for exactly that action.
  6. Verify. Real-traffic probes decide “resolved”; time to mitigate and the postmortem are recorded.

Engineering highlights

Agentic AI, done safely

  • LangGraph with a human-approval interrupt and durable Postgres checkpoints
  • Tools over MCP; step and dollar budgets enforced by the graph
  • PII redaction, injection removal, citation validation, policy interlocks, constrained decoding
  • Claude, local gemma4 via Ollama, or rules

Zero-trust security

  • Only the gateway mints credentials: ES256 + JWKS; verifiers can't forge
  • Single-use capabilities; replay store fails closed
  • OIDC (Keycloak, PKCE); every hop authenticated and tenant-bound
  • Row-level security incl. agent checkpoints; least-privilege secrets checked in CI

Distributed systems

  • Kafka ingestion, idempotent re-index, dead-letter topic
  • Hybrid retrieval (pgvector + full-text, RRF) in one Postgres transaction
  • Race-safe alert dedup with a per-service advisory lock
  • Atomic Lua token bucket on Redis with local fallback

Rigor and operations

  • Deterministic benchmark (112 incidents + held-out) as a CI gate
  • OpenTelemetry trace per incident across Java → Python → MCP; Grafana
  • Helm (hardened pods, NetworkPolicies), kind e2e, Terraform for AWS
  • 9 ADRs; a 16-chapter handbook incl. every bug found
